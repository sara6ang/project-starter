## 한 줄 시나리오 기준 (필수, 전부 통과해야 Demo Day 가능)

- [ ] 이대표가 매뉴얼을 등록할 수 있다 (사진+텍스트, 5분 이내)
- [ ] 김스태프가 TongssApp에서 그 매뉴얼을 조회하고 "다 봤어요" 체크할 수 있다
- [ ] 김스태프가 체크리스트를 실행하고 완료 처리할 수 있다
- [ ] 김스태프가 재고를 입력하고 기준값 이하 시 알림이 뜬다
- [ ] 위 모든 활동이 실 데이터로 TongssOrg의 매장 레코드에 반영된다 (더미 아님)
- [ ] 박세일즈가 org 리스트뷰에서 활성/방치 매장을 필터링할 수 있다
- [ ] 박세일즈가 매장 레코드 페이지에서 매뉴얼 수·완료율을 확인할 수 있다

## 페르소나별 성공 기준 (01_PERSONAS 참조)

| 페르소나 | 성공 기준 | 확인 방법 |
|---|---|---|
| 이대표 | "이거 보고 시작해요"라고 말하고 자기 일 하러 갈 수 있음 | 등록 소요 시간 실측 |
| 김스태프 | 사람 찾는 대신 폰 꺼내서 3초 안에 답을 봄 | "처음 보는 사람 눈"으로 실제 조작해보기 |
| 박세일즈 | 아침에 org 열면 오늘 챙길 매장이 정렬되어 있음 | 리스트뷰 정렬/필터 동작 확인 |

## "처음 보는 사람 눈" 검증 (Platform Lead가 Week 4~5에 직접 수행)

- [ ] 사전 설명 없이 TongssApp을 처음 써보고 막히는 지점 기록
- [ ] 사전 설명 없이 TongssOrg 화면을 처음 열어보고 막히는 지점 기록
- [ ] 발견한 문제는 즉시 해당 트랙 담당자에게 공유 (Show & Tell 또는 스탠드업)

## 엣지 케이스 (각 문서의 `[확인필요]` 항목에서 수집)

- [ ] 매뉴얼이 하나도 없는 상태에서 김스태프가 접속하는 경우 (TongssApp 03_USER_FLOW)
- [ ] 체크리스트를 다 못 채우고 퇴근하는 경우
- [ ] `[확인필요]` 그 외 각 스택 docs의 확인필요 항목이 QA 대상인지 검토
