Input

한 줄짜리 텍스트를 입력받을 때 사용합니다. type 속성으로 text/email/password 등을 구분하고, 좌우에 아이콘을 넣을 수 있습니다.

Type

.input[type="text"] .input[type="email"] .input[type="password"]

아이콘 슬롯

.input-group > .input-group__icon--left + .input.input--icon-left

State

Normal
.input
Focus (직접 클릭해서 확인하거나 아래는 강제 표시)
.input:focus .input.is-focus
Error
올바른 이메일 형식이 아닙니다.
.input.is-error
Disabled
.input[disabled] .input.is-disabled
