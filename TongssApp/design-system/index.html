디자인 시스템

이 페이지는 우리 프로젝트에서 사용하는 색깔, 글자, 간격 규칙을 한눈에 보여줍니다.

화면을 만들 때 여기 있는 값만 사용하세요. 코드 조각(회색 상자)을 클릭하면 값이 복사됩니다.

사용법 — 예: 버튼 배경색이 필요하면 아래 "Primary" 박스를 눌러 --color-primary를 복사한 뒤, CSS에서 background-color: var(--color-primary); 처럼 사용하세요. 전체 규칙 원본은 assets/css/tokens.css이고, 설명은 docs/07_DESIGN_SYSTEM.md에 있습니다.

Typography

글자 크기 · 굵기 · 줄 높이

글꼴은 Pretendard 하나만 사용합니다. 크기와 굵기는 아래 목록 안에서만 고릅니다.

글자 크기 (Font Size)
--fs-1212px · 아주 작은 텍스트 (도움말, 보조 설명)
--fs-1414px · 작은 텍스트 (일반 텍스트)
--fs-1616px · 기본 텍스트 (본문)
--fs-2020px · 큰 텍스트 (소제목)
--fs-2828px · 아주 큰 텍스트 (제목)
글자 굵기 (Font Weight)
--fw-400400 · 보통 (본문)
--fw-500500 · 조금 굵은 (버튼, 작은 제목)
--fw-600600 · 굵은 (제목)
--fw-700700 · 아주 굵은 (큰 제목)
줄 높이 (Line Height)
--line-height-tight1.2 · 좁은 (제목용)
--line-height-normal1.5 · 보통 (일반 텍스트용)
--line-height-loose1.8 · 넓은 (설명문용, 줄 사이 여유가 필요할 때)
글꼴 (Font Family)
--font-sansPretendard — 프로젝트 전체에서 쓰는 유일한 글꼴

Components

실제 컴포넌트

위 토큰들을 조합해서 만든 실제 UI 조각입니다. 코드 상자를 클릭하면 CSS가 복사됩니다.

Button
.button { font-size: var(--fs-14); font-weight: var(--fw-500); padding: var(--space-8) var(--space-16); border-radius: var(--radius-md); background-color: var(--color-primary); color: var(--color-white); }
Input
.input { font-size: var(--fs-16); padding: var(--space-8) var(--space-12); border: var(--border-normal); border-radius: var(--radius-md); } .input:focus { border: var(--border-focus); box-shadow: var(--shadow-focus); }
Card

카드 제목

카드 안 여백은 --space-24, 모서리는 --radius-md 입니다. 그림자 없이 헤어라인 보더로만 구분합니다.

.card { background-color: var(--color-white); border: var(--border-normal); border-radius: var(--radius-md); padding: var(--space-24); }
