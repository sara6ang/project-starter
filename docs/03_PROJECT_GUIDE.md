## 우리가 일하는 방식 (5원칙)

1. **각자 자기 트랙은 자기가 결정한다.** PM(Sara)은 트랙 안의 결정을 대신 하지 않는다.
2. **모든 기능에는 담당자가 한 명씩 있다.** 애매하게 걸쳐있는 기능을 만들지 않는다.
3. **AI가 먼저 만들고, 사람이 다듬는다.** 초안·리뷰·테스트케이스는 AI에게 먼저 시킨다.
4. **문서 없는 결정은 결정이 아니다.** 트랙을 넘는 결정은 반드시 `07_DECISIONS.md`에 남긴다.
5. **처음부터 화려하게 만들지 않는다.** 필요해지면 그때 확장한다.
