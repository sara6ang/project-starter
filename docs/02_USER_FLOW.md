## 단계별 상세

### 0단계 — 앱 진입 (Entry Code) — App/Org 인증과 무관, TongssApp 자체 로직

Tongss는 **실제 로그인 시스템을 만들지 않습니다.** 사장·직원 모두 **Entry Code**를 입력해서 들어갑니다. Salesforce는 이 진입 과정에 관여하지 않습니다 — TongssApp 안에서 코드로 매장·역할을 바로 찾습니다.

| 코드 형식 | 의미 | 예시 |
|---|---|---|
| `S` + 매장번호 + `O` | 해당 매장의 사장(Owner) | `S01O` → 1번 매장 사장 |
| `S` + 매장번호 + `E` + 직원번호 | 해당 매장의 직원(Employee) | `S01E01` → 1번 매장 1번 직원 |

- 대소문자를 구분하지 않습니다 (`s01o`, `S01o` 모두 `S01O`와 동일 — 대문자로 정규화 후 조회).
- 앱은 **하나**입니다. 사장용 앱과 직원용 앱이 따로 있는 게 아니라, 코드에 따라 사장 대시보드 또는 직원 대시보드로 이동합니다.
- 상세 흐름은 `TongssApp/docs/03_USER_FLOW.md` 참조.

```mermaid
flowchart LR
    Start["Entry Code 입력"] --> Normalize["대문자로 정규화"]
    Normalize --> Lookup["매장·역할 조회"]
    Lookup -->|O| OwnerDash["사장 대시보드"]
    Lookup -->|E| StaffDash["직원 대시보드"]
```

### 1단계 — 이대표: 초기 설정 (최초 1회성 작업)

| 순서 | 화면 | 행동 |
|---|---|---|
| 1-1 | 매뉴얼 등록 | 사진 + 짧은 텍스트로 매뉴얼 작성 (5분 이내 목표) |
| 1-2 | 체크리스트 설정 | 오픈/마감 체크리스트 항목 등록 |
| 1-3 | 재고 확인 항목 설정 | 오늘 확인할 품목 목록 등록 (수량 아님) |

**분기 처리:** 매뉴얼이 하나도 없는 상태에서 김스태프가 먼저 접속하면 → 빈 상태(Empty State) 문구 필요 (`06_VOICE_AND_TONE.md` 참조)

### 2단계 — 김스태프: 현장 사용 (매 근무일 반복)

| 순서 | 화면 | 행동 |
|---|---|---|
| 2-1 | 매뉴얼 열람 | 상황별로 찾음 — "지금 마감 시간"이면 마감 체크리스트가 먼저 노출 |
| 2-2 | "다 봤어요" 체크 | 학습 완료 표시 (감시 아닌 진행 표시) |
| 2-3 | 체크리스트 완료 처리 | 완료 시점이 이대표 대시보드에 반영 |
| 2-4 | 재고 확인 | 확인함 체크, 부족하면 "부족해요" 표시 |

### 3단계 — 데이터가 org로 전달됨

2단계에서 생긴 활동(매뉴얼 등록 수, 학습 완료, 체크리스트 완료율, 재고 확인 결과)이 통합 API를 통해 TongssOrg로 전달됩니다. **이 API 호출에는 로그인이 필요 없습니다** — Entry Code는 TongssApp 진입용이고, App↔Org 연동은 별도의 공개 엔드포인트를 씁니다 (`integration-lead/docs/02_API_CONTRACT.md` 참조). 필드 정의는 `04_DATA_CONTRACT.md` 참조.

### 4단계 — 박세일즈: org에서 확인 (필요 시 반복)

| 순서 | 화면 | 행동 |
|---|---|---|
| 4-1 | 매장 리스트뷰 | 활성/방치 매장 필터링 |
| 4-2 | 매장 레코드 페이지 | 등록 매뉴얼 수, 학습 완료율 확인 |

### 5단계 — 박오너: 지표 확인 (Demo Day 핵심 대상 아님)

박세일즈 화면에서 자동 집계되는 도입률·활성도 숫자를 확인. 별도 화면 없음.

## 하루 시나리오 예시

```
아침        이대표: S01O로 진입, (최초 1회) 신메뉴 매뉴얼 추가
피크타임    김스태프: S01E01로 진입, "재료 손질법" 확인 → 사람에게 안 물어봄
마감 시간   김스태프: 체크리스트 완료 처리, 재고 확인 → 콜라시럽 "부족해요" 표시
저녁        이대표: 대시보드에서 마감 체크·콜라시럽 부족 표시 확인
(비동기)    박세일즈: org 리스트뷰에서 이 매장이 "활성" 상태로 정렬됨을 확인
```
